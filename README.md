# brendaflores.co

Personal portfolio site — built with vanilla HTML, CSS and JavaScript.
Live at: **[brendaflores.co](https://brendaflores.co)**

## Features
- EN/ES language toggle
- Smooth scroll navigation
- Scroll-triggered animations
- Custom cursor
- Fully responsive
- SEO basics: sitemap, robots.txt, Open Graph/Twitter cards, favicon
- Lead capture form (Formspree) on `/diagnostico.html` and `/ejemplo/`

## Stack
HTML · CSS · Vanilla JS · Google Fonts · GitHub Pages

## Analytics
Centralized in `analytics.js` (GA4 + Microsoft Clarity), loaded by every page. IDs and behavior are documented in the file's header comment — it's the only place they get edited.

## Run locally
Just open `index.html` in your browser, no build step needed.
